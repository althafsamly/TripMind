# TripMind AI - Smart Travel Planning & Tourism Assistant

TripMind is an intelligent AI-powered travel planning platform designed for exploring Sri Lanka. It combines Google Gemini AI, Amadeus Hospitality GDS, and OpenStreetMap to deliver dynamic itineraries, realistic budget estimations, authentic food spots, hotel booking options, and a real-time Emergency SOS medical assistance system.

## Key Features

- **AI-Powered Itineraries:** Dynamic multi-day day-by-day itineraries personalized by budget, duration, and group style.
- **Smart Seasonal Date Recommendations:** Analyzes Sri Lankan monsoon cycles (Southwest vs Northeast) using Gemini AI to recommend optimal destinations for chosen travel dates.
- **Voice AI Trip Planner:** Natural language voice and text parser powered by Google Gemini.
- **Emergency SOS Center:** Real-time 20km nearest hospital locator using OpenStreetMap Overpass API and W3C Device Geolocation with emergency trauma fail-safe databases.
- **Authentic Culinary & Transport Insights:** Verified local dining spots and terrain-adjusted vehicle recommendations.

## Tech Stack

- **Frontend:** React 19, Vite, React Router DOM, Pure Modular CSS
- **Backend:** Node.js, Express 5, REST APIs
- **Database:** MongoDB Atlas, Mongoose ODM
- **AI & External APIs:** Google Gemini AI (@google/genai), Amadeus Travel API, OpenStreetMap Overpass API, Pexels CDN, Wikimedia Commons
